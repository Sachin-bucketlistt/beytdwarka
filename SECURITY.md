# Security Policy

## Supported versions

Security fixes are applied to the latest code on `main`.

## Reporting a vulnerability

Please **do not** open a public issue for security reports.

Use [GitHub private vulnerability reporting](https://github.com/Sachin-bucketlistt/beytdwarka/security/advisories/new) instead.

Include:

- A description of the issue
- Steps to reproduce
- Affected URLs or files
- Any proof-of-concept that stays limited to this project

You should receive an acknowledgement when the report is reviewed. Please give us time to investigate before any public disclosure.

## Safe harbor

Security research on this repository is welcome when it stays within this project, avoids accessing other people's data, and does not disrupt GitHub Pages or related services.
